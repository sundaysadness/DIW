Sobre

Este site reúne pontos turísticos e outros locais interessantes de Belo Horizonte, junta informações como localização, custo, característica do ambiente, e descrição em um lugar só.

As páginas são montadas em JavaScript a partir de uma estrutura JSON, com layout responsivo feito com Bootstrap.
